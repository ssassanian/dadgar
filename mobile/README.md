# dadgar-mobile — اپ نیتیو موبایل دادگر (Flutter)

| مشخصه | مقدار |
|---|---|
| مخزن | `ssassanian/dadgar` — پوشه‌ی **`mobile/`** در مونوریپو (تصمیم مدیر: «یک ریپو باشه»، 2026-10-29 — CMD-016)؛ جدایی دایرکتوری کامل از `web/` (قانون S-1 نسخه 2.1) |
| مرجع الزامی | [DOC-04 نسخه 2.1](../docs/04-MOBILE-NATIVE-SPEC.md) — **تایید مدیر 2026-10-29 + بازنگری مونوریپو (CMD-016)** |
| فریمورک | Flutter (پایدار 3.41 — پین‌شده در CI) + Dart |
| وضعیت | **M0 — اسکلت معماری** |

> ⚠️ پوشه‌ی `mobile/` به هیچ عنوان فایل، ابزار یا کدی با `web/` اشتراک ندارد — دو دیوار مستقل: تفکیک دایرکتوری + تفاوت زبان (Dart در برابر JavaScript). تنها نقطه‌ی اتصال، قرارداد REST API نسخه‌دار است (DOC-04 §۵). هر تخطی = توقف کار و گزارش به مدیر (S-10).

## ده قانون جدایی (خلاصه — متن کامل در DOC-04 §۳ نسخه 2.1)

`S-1` جدایی دایرکتوری کامل `mobile/` در برابر `web/` — صفر فایل مشترک · `S-2` صفر اشتراک کد/استایل/فونت با وب · `S-3` صفر تغییر در وب مگر دو افزوده‌ی ثبت‌شده‌ی API · `S-4` تنها اتصال: REST API نسخه‌دار · `S-5` CI/CD مستقل (workflow جدا با فیلتر مسیر `mobile/**`) · `S-6` secret جدا و هرگز در کد/باینری · `S-7` نسخه‌گذاری مستقل `M-x.y.z` · `S-8` e2e جدا (Maestro) · `S-9` کوکی وب ≠ توکن موبایل · `S-10` تخطی = توقف + گزارش

## ساختار (DOC-04 §۶)

```
lib/
├── main.dart            # ورود — ProviderScope
├── app/                 # ریشه اپ، روتر (M1: go_router)، تم
├── design/              # توکن‌های دیزاین مستقل + فونت Vazirmatn باندل
├── features/            # auth | cases | book | bill | msg | docs (فازها)
└── shared/              # ویجت‌های عمومی
assets/fonts/vazirmatn/  # وزن‌های 400/500/700
```

## فازها (DOC-04 §۱۱)

`M0` اسکلت+CI+پالت ← `M1` ورود/توکن/OTP ← `M2` پرونده‌ها ← `M3` نوبت‌دهی شمسی ← `M4` مالی ← `M5` پیام+اسناد ← `M6` پوش FCM ← `M7` سخت‌سازی+انتشار اندروید ← `M8` iOS (Codemagic)

## توسعه و تست محلی

```bash
flutter pub get
flutter analyze
flutter test
```

CI (`mobile-ci.yml`): فقط روی تغییر مسیر `mobile/**` اجرا می‌شود: `pub get → analyze --fatal-infos → test` (دروازه‌ی M0 — DOC-04 §۹).
