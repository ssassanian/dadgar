## ۲) ممیزی فوتر (پیش از طراحی)

- **SPA `foot()`:** شش ستون + بلوک موقت `.ftmp` («دسترسی موقت به همه‌ی صفحات — در طراحی نهایی برداشته می‌شود») + علامت آبی `.big`
- **لایه‌ی عمومی `page.html`:** فوتر تک‌نوار ۸لینکی — هم‌خوان با SPA نیست
- ممیزی مسیر SPA (استخراج `RT`، ۶۷ مسیر): ۳۰/۳۲ مقصد فوتر موجود؛ فقط `/guide` و `/auth` غایب‌اند (`/login` معادل فعال)

## ۳) پایه‌ی مهارت‌محور طراحی

- `--design-system "law firm trust professional"`: الگوی **Trust & Authority + Conversion**، سبک **Accessible & Ethical**، رنگ «سرمه‌ای اقتدار + طلایی اعتماد» — هم‌راستای طبیعی با هویت فعلی دادگر → **صفر رنگ جدید**؛ فقط توکن‌های فعلی (`--b1/--cy/--warm/--foot/--gold`، لاله‌زار/وزیرمتن)
- `ux`: skip-link، فوکوس مرئی، 44px، اسکرول نرم؛ `icons`: آیکون تزئینی `aria-hidden`/اجتماعی با `aria-label`
- `landing` دو پرس‌وجو → **۰ نتیجه** (با یک retry) → ساختار فوتر از اصول ux + پیش‌فرض‌های عمومی (تصریح طبق قرارداد مهارت)
- چک‌لیست پیش از تحویل: SVG به‌جای ایموجی، گذار ۱۵۰-۳۰۰ms، کنتراست ≥4.5:1، reduced-motion، واکنش‌گرای ۳۷۵/۷۶۸/۱۰۲۴/۱۴۴۰

## ۴) خروجی طراحی

ساختار پنج‌بخشی: **نوار CTA شیشه‌ای** (گوشه ۲۲px، سوشده روی لبه، دکمه‌ی گرم «رزرو مشاوره») → **گرید ۵ ستونی** (برند+اجتماعی / خدمات / موسسه / منابع و دانش / تماس و شعب) → **علامت آبی `.big`** → **نوار پایینی** (© ۱۴۰۵ + صفحات قانونی با «·» + پیش‌نمایش موبایل). حذف `.ftmp` = نقطه‌ی تصمیم مدیر (جایگزین عمومی: `/sitemap`).

- سند طراحی: `download/dadgar-footer-redesign-spec.md`
