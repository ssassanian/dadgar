## تفسیر و اجرا

مدیر خواستار دیدن «نسخه موبایل» از طریق خودِ سایت زنده است — یعنی پیش‌نمایشی که در CMD-019 تحویل شد
(`download/dadgar-mobile-M1-preview.html`؛ پنج صفحه‌ی واقعی اپ با توکن‌های پالت D-3، وفادار به کد `mobile/lib/`)
این‌بار باید **روی همان سایت production میزبانی شود** و از **فوتر صفحه‌ی اصلی** قابل دسترس باشد.

### ۱) مسیر میزبانی: `/mobile-preview`
- معماری سایت هیچ سروِ استاتیک مستقیمی ندارد (وارسی زنده: `dynamic/index.html` مستقیم = 404)؛ همه‌چیز از توابع سرورلس می‌گذرد.
- بنابراین طبق **همان الگوی موجود** (`api/html.js`) عمل شد:
  - `web/dynamic/mobile-preview.html` — محتوای پیش‌نمایش، کپی بایت‌به‌بایت فایل CMD-019 (دقیقاً ۱۱۳۲۴ بایت).
  - `web/api/mobile-preview.js` — تابع سرورلس جدید: خواندن محتوا (با کش ماژول)، `Content-Type: text/html; charset=utf-8`، `Cache-Control: public, max-age=300` و `X-Robots-Tag: noindex` (بهداشت سئو — این صفحه موقتی است تا انتشار واقعی در M7).
  - `web/vercel.json` — **دو افزودنی صرف**: یک مدخل در `builds` (با همان `includeFiles: dynamic/**`) و یک route `/mobile-preview` **پیش از** catch-all `/(.*)` تا توسط ۴۰۴ بلعیده نشود.

### ۲) لینک فوتر
در `web/dynamic/index.html` — فقط **یک خط**، بلافاصله پس از خط کپی‌رایت و پیش از بلوک `#fln` (که با JS بازساخته می‌شود و روی همسایه‌های خود بی‌اثر است):

```html
<p style="margin-top:12px"><a href="/mobile-preview" style="color:#ffd9a0;text-decoration:none;font-size:15px">نسخه موبایل دادگر — پیش‌نمایش اپ</a></p>
```

رنگ `#ffd9a0` همان رنگ عنوان‌های فوتر موجود است تا لینک با زبان بصری صفحه یکدست بماند.

### ۳) محدوده‌ی تغییر `web/` (نقض کنترل‌شده — به حکم صریح مدیر)
کنترل «`web/` دست‌نخورده» طبق ماده‌ی مربوطه فقط با دستور صریح مدیر قابل نقض است؛ این دستور همان حکم است.
کل تغییر: **سه افزوده + یک ویرایش تک‌خطی** — صفر تغییر در ۴۶ مسیر API، جریان کوکی، لایه‌ی امنیت و منطق موجود
(وارسی زنده پس از دیپلوی: `/api/__probe__` = 404 JSON استاندارد `{"error":"یافت نشد."}` — رفتار موجود سالم).

## تست

### محلی (سه‌بخشی — همه سبز)
1. فراخوانی شبیه‌سازی‌شده‌ی `api/mobile-preview.js`: 200 + `text/html; charset=utf-8` + دقیقاً ۱۱۳۲۴ بایت + `<!DOCTYPE html>` + نشان فارسی.
2. `vercel.json`: مدخل build موجود + ترتیب route (`/mobile-preview` قبل از catch-all).
3. فوتر: `href="/mobile-preview"` دقیقاً یک‌بار در `dynamic/index.html`.

### زنده (پس از دیپلوی گیتِ کامیت `a6e1c27`)
| وارسی | نتیجه |
|---|---|
| `GET /mobile-preview` | **200** + سرصفحه‌های درست (`content-type`, `cache-control`, `x-robots-tag: noindex`) |
| `GET /` | **200** + لینک «نسخه موبایل دادگر — پیش‌نمایش اپ» در فوتر |
| `GET /api/__probe__` | 404 JSON استاندارد — مسیرهای API موجود دست‌نخورده |
