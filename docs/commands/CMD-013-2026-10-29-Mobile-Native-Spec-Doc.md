## تفسیر ثبت‌شده

1. «فعلا اینجا در حال ساخت هستیم» — پروژه‌ی وب همین‌طور فعال می‌ماند؛ موبایل پروژه‌ای موازی و آینده است
2. خواسته: **سند فنی** برای نسخه‌ی موبایل که (الف) روش کدنویسی، (ب) سازوکار جدایی کامل از وب و (ج) بهترین حالت بر اساس تحقیق از وب/GitHub/منابع برنامه‌نویسی را مشخص کند
3. قید مدیر: **موبایل باید نیتیو باشد** و پس از تایید، این سند **مرجع الزامی** ادامه‌ی کار است
4. **ممنوعیت:** تا تایید کتبی مدیر، هیچ کدی برای موبایل نوشته نمی‌شود (ادامه‌ی روح CMD-012)
