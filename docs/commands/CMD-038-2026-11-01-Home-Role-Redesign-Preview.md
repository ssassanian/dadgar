# CMD-038 — پرسش نقش‌ها و بازطراحی خانه‌ی اپ موبایل (قبل/بعد)

- **تاریخ:** ۱۴۰۴/۰۸/۱۴ (2026-11-01)
- **فرمانده:** مدیر پروژه
- **متن فرمان:** «یعنی صفحه خانه بهتر از این نمیشد طراحی کنی؟ صفحه خانه مخصوص چه کسی است؟ ایا این مخصوص وکیل هست؟ مشتری؟ یا ادمین؟»
- **وضعیت:** پیش‌نمایش طراحی تحویل شد — کدنویسی منتظر تایید مدیر

## پاسخ پرسش نقش‌ها

| صفحه | صاحبش |
| --- | --- |
| خانه‌ی سایت (وب عمومی) | مشتری بالقوه (مراجع بدون پرونده) — اعتمادسازی و تبدیل به مشاوره |
| خانه‌ی اپ موبایل | **مشتری واردشده (موکل)** — امیر |
| داشبورد وکیل | وکیل — وب، پشت ورود (خارج از اپ M1) |
| داشبورد ادمین | مدیر موسسه — وب، پشت ورود (خارج از اپ M1) |

## نقد پذیرفته‌شده‌ی نسخه‌ی CMD-037 (home.png)

1. چهار کاشی عدد ۲×۲ چهره‌ی نرم‌افزار حسابداری داشت؛ مهم‌ترین اتفاق (جلسه‌ی دادگاه) زیر آمارها پنهان بود.
2. «بدهی باز» دومین عنصر درشت صفحه بود — اولین نگاهِ موکلِ نگران نباید پول باشد.
3. صفحه به «چه کار کنم؟» جواب نمی‌داد — هیچ اقدام اصلی نداشت.
4. وکیل (مهم‌ترین رابطه‌ی موکل) در خانه غایب بود.

## تغییرات نسخه‌ی v2 (فقط سلسله‌مراتب — صفر تغییر زبان طراحی)

- کارت قهرمان: جلسه‌ی دادگاه (پرونده‌ی DD-۱۴۰۴-۰۱۷، ۵ روز مانده، شعبه‌ی ۱۴، ساعت ۰۹:۰۰) + عنصر امضایی «مسیر پرونده» + دکمه‌های جزئیات/پیام.
- سه اقدام فوری: ارسال سند، رزرو نوبت، پرداخت فاکتور.
- کارت «وکیل شما»: رضا محمدی + آخرین پیام خوانده‌نشده + تماس/پیام.
- «پرونده‌های من»: دو ردیف در جریان + پیوند هر ۳ پرونده.
- مالی به یک ردیف آرام تبدیل شد: ۱ فاکتور پرداخت‌نشده · ۱۸٬۵۰۰٬۰۰۰ تومان.
- توکن‌های D-3، تب‌های پنج‌گانه، فونت، قواعد لمس و عنصر امضایی عیناً CMD-037.
