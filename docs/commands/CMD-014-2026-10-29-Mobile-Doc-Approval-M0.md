## مانع واحد برای تکمیل M0 (نیازمند یک اقدام مدیر)

توکن گیت‌هاب فعلی **fine-grained** است و فقط به مخزن `dadgar` دسترسی دارد؛ مخزن تازه‌ساخته‌ی `dadgar-mobile` خارج از scope آن است:

- `GET /repos/ssassanian/dadgar-mobile` → 404 (خارج از scope)
- `git push` → 403 «Write access to repository not granted»

**اقدام مورد نیاز مدیر** (GitHub → Settings → Developer settings → Fine-grained tokens → ویرایش توکن فعلی):
- در Repository access، مخزن `dadgar-mobile` را اضافه کند (یا «All repositories» را انتخاب کند)
- مجوز `Contents: Read and write` برای آن مخزن فعال باشد

پس از این اقدام، با یک دستور («ادامه») push و سبزشدن CI انجام می‌شود و M0 با دروازه‌ی «اپ خالی سبز روی CI» بسته می‌شود.
