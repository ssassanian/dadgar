## تفسیر ثبت‌شده

1. فرمان «ادامه» پس از تکمیل فاز ۱ CMD-044 = ادامه‌ی فازبندی همان سند؛ §باقی‌مانده‌ی
   CMD-044 فاز ۲ را چنین تعریف کرده بود: «بازطراحی D-3 صفحه‌های پرونده‌ها/جزئیات
   به ردیف‌های `r-main/r-side` طرح».
2. مرجع طرح = پروتوتایپ تاییدشده‌ی CMD-041 (`design-preview/prototype.html` توابع
   `bCases`/`bDetail` + `app.css`) و شات‌های تاییدشده‌ی CMD-037 — صفر رنگ/فونت/داده‌ی
   جدید خارج از پالت D-3.
3. **تداخل‌های طرح↔قرارداد بدون حدس حل شد (ماده ۳ / S-4):**
   - **فیلتر چیپ‌ها**: قرارداد سرور پارامتر وضعیت ندارد (فقط `page`) → چیپ‌های
     «همه/در جریان/بسته» ردیف‌های بارگذاری‌شده را صافی می‌کنند؛ شمارنده‌ی «در جریان»
     زیرنویس نوار بالا فقط وقتی همه‌ی صفحات رسیده‌اند نمایش داده می‌شود (صداقت
     صفحه‌بندی).
   - **F1 (۶↔۵ مسیر پرونده)**: پنل «مسیر پرونده» با پنج وضعیت واقعی سرور
     (`waiting→done`) و قرص «مرحله‌ی X از ۵»؛ شش مرحله‌ی حقوقی پروتوتایپ فقط با
     افزوده‌ی سرور (D-6/حکم مدیر) — F1 همچنان باز.
   - **گفتگو**: پنل فقط برای پرونده‌ی دارای وکیل (assigned/running/done) طبق قاعده‌ی
     سرور فعال می‌شود؛ وضعیت‌های waiting/proposing پیام **عین سرور**
     (`MessagesContract.chatNotActiveMessage`) می‌بینند و **هیچ فراخوانی** زده نمی‌شود
     (تست گیت دارد: `messageCalls == 0`).
   - **اسناد پرونده**: پالایش فهرست واقعی `GET /api/documents` بر `case_id` (قرارداد
     فهرست پرونده‌محور ندارد) — حداکثر ۲ سند + لینک «همه‌ی اسناد گاوصندوق».
   - **ورود «ثبت پرونده جدید»**: پروتوتایپ ۵۲یاله آن را ندارد (F3 باز) ولی حذف
     قابلیت M2 مجاز نبود → طبق شات تاییدشده‌ی CMD-037 به‌صورت دکمه‌ی شبح پایان فهرست
     حفظ شد؛ FAB حذف شد (خارج از زبان طرح).
   - **قرص‌های وضعیت**: فهرست = همگی خنثی (عین `bCases`)؛ جزئیات = داده‌ی سرمه‌ای برای
     وضعیت‌های فعال و خنثی برای «بسته‌شده» (عین `bDetail`).
4. اجرای هم‌زمان F4/F5 روی کدهای نو و عنصر امضایی: چیپ‌ها لمس ۴۸dp (تصحیح چیپ ۳۴px
   خود طرح)، برچسب نوار مسیر ۱۲sp (بود ۱۱)، رنگ‌های نوار مسیر عین CSS (`--rule`/
   `--faint`/`--pill-data-bg`).
