# CMD-029 — تصمیم معماری و شروع تکمیل نسخه وب

- **تاریخ:** 2026-10-30
- **دستور مدیر:** مدیر با پیشنهاد معماری موافقت کرد و دستور داد تصمیم مستند شود و کار روی نسخه وب آغاز گردد.
- **دامنه:** فقط نسخه وب؛ نسخه موبایل در این فاز فریز است.

## تصمیم معماری

1. نسخه وب و نسخه موبایل دو کلاینت مستقل هستند و کد، رابط کاربری و گرافیک یکدیگر را مستقیماً به اشتراک نمی‌گذارند.
2. بک‌اند و قراردادهای API موجود، لایه مشترک داده و سرویس هستند؛ هر کلاینت مصرف‌کننده مستقل آن است.
3. نسخه وب فعلی روی `web/` و Vercel اجرا می‌شود و شامل HTML عمومی، APIهای سرورلس، آداپتور دیتابیس و منطق امنیتی است.
4. نسخه موبایل فعلی در `mobile/` با Flutter توسعه می‌یابد و در این فاز هیچ فایل موبایلی تغییر نمی‌کند.
5. ترتیب اجرا: تکمیل طراحی و ساختار صفحات عمومی وب، سپس اتصال تعاملی صفحات به APIهای موجود؛ تغییر دیتابیس یا API فقط با دستور جداگانه انجام می‌شود.

## محدوده فاز اول وب

- تثبیت صفحه اصلی و سیستم ناوبری عمومی وب.
- ایجاد صفحات مستقل تعرفه‌ها، سوالات متداول، تماس با ما و ورود/ثبت‌نام در معماری وب.
- ایجاد لندینگ‌های خدماتی بر اساس محتوای تاییدشده مدیر.
- حفظ مسیرهای API، امنیت، دیتابیس و نسخه موبایل بدون تغییر مگر با دستور صریح.

## معیار توقف

هرجا متن حقوقی، قیمت، ادعای تخصص، مسیر احراز هویت یا قرارداد API نیازمند تصمیم جدید باشد، قبل از کدنویسی از مدیر استعلام می‌شود.
