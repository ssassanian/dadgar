## ۲) محتوای خروجی

- **۱ صفحه از حالت نمایشی خارج شد**: گاوصندوق اسناد مشتری (`cDocs`) — مجموع صفحات واقعی فاز ۳: **۲۰ از ۲۳** (+۱ صفحه‌ی عمومی)
- **۴ مسیر API جدید** (`GET /api/documents`، `POST /api/cases/:id/documents`، `GET /api/documents/:id/file`، `DELETE /api/documents/:id`) + توسعه‌ی سبک `GET /api/cases?select=1` (انتخابگر پرونده) — همه با لایه‌های امنیتی فاز ۱ (نشست/CSRF/نقش/نرخ/پارامتری) + Audit سه‌گانه (`doc_upload`/`doc_download`/`doc_delete`) — جمع مسیرهای API: **۴۲**
- **مدل پرونده‌محور خودِ پروژه**: سند همیشه به یک پرونده چسبیده است؛ مشتری و وکیلِ تخصیص‌یافته بارگذاری می‌کنند، «گاوصندوق» مشتری همه‌ی اسناد پرونده‌های او را نشان می‌دهد (شامل اسناد بارگذاری‌شده‌ی وکیل) — دقیقاً مطابق `documents(case_id NOT NULL)` مرجع، بدون تغییر اسکیما
- **رمزنگاری AES-256-GCM در سنگین‌ترین لایه**: هم نام فایل (`doc.name`، کلید فیلد) و هم **محتوای کامل فایل** (`doc.content`، کلید مستقل `K.file` از فاز ۱) — تست خودکار صراحتاً «plaintext نباشد» را روی دیتابیس واقعی الزام می‌کند (هم‌سو با مستندات خود پروژه: اسناد حساس‌ترین داده‌اند)
- **آپلود باینری خام بدون multipart**: فایل در body، نام فایل در هدر `x-file-name` (URL-encoded)؛ سقف ۴ مگابایت (۴13)؛ استفاده از `raw` (از ابتدا در dispatcher پیش‌بینی شده بود) + سقف بدنه‌ی JSON حالا per-route قابل تنظیم است (`opts.bodyLimit` — رفتار مسیرهای موجود عیناً ثابت)
- **دانلود امن**: همیشه `Content-Disposition: attachment` + نام استاندارد RFC 5987 (نام فارسی سالم) + لیست سفید mime (غیرمجاز → `application/octet-stream`) + `nosniff` + `no-store` — تست بایت‌به‌بایت
- **حریم خصوصی و حذف سالم**: 404 ضدافشا در آپلود/دانلود/حذف؛ حذف فقط توسط بارگذارِ سند یا مدیر (مشتری نمی‌تواند سند وکیل را حذف کند)؛ «سطح دسترسی» نمایشیِ UI از عضویت پرونده استنتاج می‌شود (وکیل دارد = «اشتراک با وکیل»، نه = «محرمانه») — بدون ستون جدید
- **فرانت‌اند**: `web/scripts/inject-docs.py` (زنجیره CMD-003←004←005←006←007←008، idempotent) — VR.cDocs + سه هندلر واقعی `data-docup`/`data-docdl`/`data-docdel` با پیش‌دستی قبل از هندلر نمایشی `data-md`؛ دانلود با blob و نام پیشنهادی فارسی
- **بدون تغییر اسکیما و بدون تغییر فایل مرجع** — فایل مرجع `dadgar/` دست‌نخورده
