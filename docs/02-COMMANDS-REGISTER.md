# دفتر ثبت دستورات مدیر (Commands Register)

| مشخصه | مقدار |
|---|---|
| شماره سند | DOC-002 |
| نسخه | 2.0 |
| وضعیت | **سند رسمی ثبت و شماره‌گذاری تمام دستورات مدیر پروژه** |
| مبنای قانونی | ماده ۱۵ قانون عمومی ([00-CONSTITUTION.md](00-CONSTITUTION.md)) |

> طبق قانون عمومی، **تمامی دستورات مدیر باید در گیت‌هاب مستندسازی شود**. این دفتر مرجع رسمی ثبت و شماره‌گذاری دستورات است. متن کامل هر دستور در مسیر `docs/commands/CMD-XXX-….md` نگهداری می‌شود.

---

## قواعد شماره‌گذاری

- هر دستور مدیر یک شماره یکتا می‌گیرد: `CMD-XXX` (ترتیبی و بدون تکرار).
- فایل مستند هر دستور: `docs/commands/CMD-XXX-YYYY-MM-DD-عنوان-کوتاه.md`
- وضعیت هر دستور یکی از این‌هاست: `ثبت‌شده` / `در حال اجرا` / `اجرا شد` / `متوقف — در انتظار پاسخ مدیر`
